# Perception Neuron to LSL relay

## Install

```
$ git clone https://github.com/jamieforth/pylsl-pn.git
$ cd pylsl-pn
$ uv sync
```

## Updating

```
$ git pull
$ uv sync
```

## Running tests

```
$ uv run pytest
```

## Running relay

Run relay with default options:

```
$ uv run lsl-pn
```

To print help and additional options:

```
$ uv run lsl-pn --help
```
